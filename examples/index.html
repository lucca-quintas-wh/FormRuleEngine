Exemplos

Uma página por assunto, cada uma rodando de verdade no navegador. O HTML que você lê em cada bloco é o HTML que está executando — ele é clonado de um <template> e impresso ao lado, então não existe divergência entre a documentação e a demonstração.

Como rodar: sirva a pasta por HTTP a partir da raiz do repositório e abra examples/index.html. Abrir por file:// funciona na maioria dos exemplos, mas o caminho testado é: 

python3 -m http.server 8000
# depois: http://localhost:8000/examples/

Três coisas para saber antes de começar

1. Ordem de carregamento

Núcleo, depois os plugins que você usa, e o bootstrap por último. O bootstrap registra só os plugins que encontrar carregados — plugin ausente é ignorado em silêncio, então você paga apenas pelo que usa. 

<script src="../src/form-rule-engine.js"></script>
<script src="../src/plugins/form-rule-base.js"></script>   <!-- sempre -->
<script src="../src/plugins/form-rule-visible.js"></script>
<script src="../src/form-visibility-v2.js"></script>        <!-- por último -->

2. O formulário precisa se declarar

O bootstrap só olha para form[data-form-visibility="true"]. Sem esse atributo nada acontece, e não há aviso.

3. Comparação é de string

O valor de um campo é sempre string. {"Quantidade": 1} é falso quando o input contém "1" — escreva {"Quantidade": "1"}. Os comparadores numéricos (>, <, >=, <=) são exceção: passam por parseFloat.

Nota de honestidade. Alguns exemplos precisam de jQuery e de um servidor. Para rodarem offline, esta pasta traz um substituto mínimo de jQuery (assets/jquery-shim.js) e um servidor falso (assets/mock-server.js). Nenhum dos dois faz parte da engine — no seu projeto use jQuery de verdade e seu backend de verdade. As páginas indicam no topo o que cada uma carrega.
